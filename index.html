ตั้งค่าระบบและสำรองข้อมูล

1. การตั้งค่า Supabase Cloud

หมายเหตุความปลอดภัย: ค่า Anon/Publishable Key เป็นคีย์สาธารณะสำหรับระบุโปรเจกต์เท่านั้น การป้องกันข้อมูลจริงทำงานผ่าน Row Level Security (RLS) และ JWT ของบัญชีผู้ใช้ ห้ามใส่ service_role key ในหน้านี้เด็ดขาด

สถานะการเชื่อมต่อ: โหมดบันทึกข้อมูลในเครื่อง — ข้อมูลยังไม่ซิงก์ข้ามอุปกรณ์

2. สถานะบริการวิเคราะห์ใบเสร็จด้วย AI (Gemini)

เพื่อความปลอดภัยสูงสุด ระบบไม่อนุญาตให้กรอก Gemini API Key ในเบราว์เซอร์ การตั้งค่า GEMINI_API_KEY และ GEMINI_MODEL ต้องตั้งผ่าน Supabase Edge Function Secrets เท่านั้น

สถานะ AI: ยังไม่ได้ตั้งค่า AI (ต้องเชื่อมต่อ Supabase และเข้าสู่ระบบเพื่อเรียกใช้งาน Edge Function: analyze-receipt)

3. สำรองและนำเข้าข้อมูล (Export / Import Backup)

คำเตือน: ไฟล์สำรองมีข้อมูลการเงินส่วนบุคคลของคุณ กรุณาจัดเก็บไว้ในที่ปลอดภัยและไม่เผยแพร่สู่สาธารณะ

บัญชีผู้ใช้และการซิงก์ข้ามอุปกรณ์

สถานะปัจจุบัน: ยังไม่ได้เข้าสู่ระบบ (ทำงานในโหมดบันทึกข้อมูลในเครื่อง)

ยืนยันการดำเนินการ

แบ่งเงินเดือนออกเป็น 6 ส่วน (Fix ประจำเดือน)

ระบบตั้งค่ายอด Fix รายเดือนตามสูตรของคุณไว้ให้แล้ว (เก็บสร้างบ้าน 13,000 / ลงทุนหุ้น 6,500 / ประกันพ่อ 1,300 หรือ 2,600 / เงินสะสมประกันแดน 2,900 แยกที่กระปุก 6 / ให้น้องมายด์ 2,000 / น้ำ-ไฟ-โทรศัพท์-เรียนพิเศษลูก 6,500) สามารถปรับแก้ตัวเลขก่อนยืนยันได้

ประกอบด้วย: ประกันพ่อ (1,300) + ให้น้องมายด์ (2,000) + ค่าน้ำ/ค่าไฟ/ค่าโทรศัพท์/ค่าเรียนพิเศษลูก (6,500)

ยอดกันเงิน (ข้อ 1 + 2 + 3 + 6) = ฿32,200.00 | กรอกยอดเงินเดือนรวมเพื่อคำนวณข้อ 5 อัตโนมัติ
